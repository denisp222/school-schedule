# Основные функции Хронографа и нового приложения

Сверено с 133 разделами локальной справки установленного ХроноГрафа 3.0.
Это сопоставление функций; исходный код старой программы не предоставлен.

| Работа завуча | Реализация |
|---|---|
| Учреждение, учебный период, звонки | Настройки |
| Классы, ученики, преподаватели, предметы, кабинеты | Справочники |
| Недельная сетка часов и назначение нагрузки | Учебный план, фильтры, отчёт распределения |
| Рабочие дни и часы, ограничения | Общий редактор ограничений |
| Парные часы, группы, закрепления | Учебный план, редактор и проверка расчёта |
| Общее рабочее поле расстановки | Базовая неделя по дням, классам, учителям и кабинетам |
| Назначение, отмена и обмен уроков | Двойной щелчок, перетаскивание, отмена и повтор правок |
| Локатор нераспределённых часов | Распределение под общей таблицей и в учебном плане |
| Предварительный и полный автоматический расчёт | Достраивание часов и генерация полной недели в черновике |
| Сохранение нового постоянного расписания | Ввод редакции с даты с сохранением предыдущих дат |
| Тетрадь замен, ежедневные правки | Отсутствия, подбор вариантов, журнал, подсветка |
| Печать и отчёты | Word в школьной таблице, CSV нагрузки, плана и журнала |
| Сохранение проекта, автосохранение, копии | Локальная база, история, полная переносимая копия |
| Дополнительная занятость | Началка и индивидуальные занятия отдельным списком |

Новое: помощник проверяет учебный план и предлагает изменения часов с
предпросмотром, сохраняемыми диалогами и действующим лимитом расходов.
Он получает компактный план и результаты проверок, не всю сетку уроков.
Его предложения применяются в черновике; расстановка проверяется отдельно.

Границы: произвольный импорт закрытого формата .chngf, старые ведомости ЕГЭ
и все виды идентичных потоков старой программы пока не воспроизведены.
Существующее школьное расписание перенесено; новые проекты переносятся
полной резервной копией. Вторая смена и рабочая суббота исключены условиями
этой школы. Полное совпадение каждого старого пункта меню не заявляется.
