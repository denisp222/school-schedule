# Основные функции Хронографа и нового приложения

Сверено с 133 разделами локальной справки установленного ХроноГрафа 3.0.
Это сопоставление функций; исходный код старой программы не предоставлен.

| Работа завуча | Реализация |
|---|---|
| Учреждение, учебный период, звонки | Настройки |
| Классы, преподаватели, предметы, кабинеты | Справочники |
| Список учеников и выбор предметов ЕГЭ | «Ученики и экзамены»: карточки, фильтры, импорт CSV, ведомости Word/CSV |
| Недельная сетка часов и назначение нагрузки | Учебный план, фильтры, отчёт распределения |
| Рабочие дни и часы, ограничения | Общий редактор ограничений |
| Парные часы, группы, закрепления | Учебный план, редактор и проверка расчёта |
| Потоки, поточно-спаренные часы и одинаковое время групп | «Поточные занятия»: общие классы, подгруппы и именованные связи строк; проверяются обоими алгоритмами |
| Общее рабочее поле расстановки | Базовая неделя по дням, классам, учителям и кабинетам |
| Назначение, отмена и обмен уроков | Двойной щелчок, перетаскивание, отмена и повтор правок |
| Локатор нераспределённых часов | Распределение под общей таблицей и в учебном плане |
| Предварительный и полный автоматический расчёт | Достраивание часов и генерация полной недели в черновике |
| Сохранение нового постоянного расписания | Ввод редакции с даты с сохранением предыдущих дат |
| Тетрадь замен, ежедневные правки | Отсутствия, подбор вариантов, журнал, подсветка |
| Печать и отчёты | Word в школьной таблице, CSV нагрузки, плана и журнала |
| Сохранение проекта, автосохранение, копии | Локальная база, история, полная переносимая копия |
| Дополнительная занятость | Началка и индивидуальные занятия в общей занятости учителей и кабинетов, нагрузке и Word-отчётах |
| Чередование недель | Четыре недели по календарю, отдельное редактирование, карточки учеников, изменения на дату и ввод новой редакции |
| Загрузка другого проекта Хронографа | .chngf читается установленным Хронографом во временной копии, затем показывается предпросмотр; доступен и импорт четырёх штатных HTML-отчётов |

Помощник работает в общем чате: объясняет функции, показывает нагрузку,
переходит к разделам и готовит изменения ограничений и справочников для
подтверждения. Справка, нагрузка и сводка экзаменов работают локально.
При обращении к модели ФИО учеников и их личные карточки не передаются.

Для .chngf нужен установленный Хронограф 3.0 Мастер: его закрытый формат
читает сам оригинал. Старая программа не включается в установщик нового
приложения; после миграции для повседневной работы она не требуется.
Импорт заменяет проект после подтверждения. Звонки и учебный период остаются
текущими, их нужно проверить в настройках. Ведомости экзаменов содержат
выбор предметов и списки, не государственную регистрацию экзаменов.
Вторая смена и рабочая суббота исключены условиями этой школы.
