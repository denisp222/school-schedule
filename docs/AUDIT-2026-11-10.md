# Проверка отчёта и исправления 2.16.0

Исходный отчёт проверен по коду. Его копия не включена в Git, поскольку содержит
школьные фамилии. Рабочие данные и исходные шаблоны не обезличивались на месте.

## Исправлено

- §1.1: автодобор годовых часов использует неделю начала учебного года, либо
  текущую неделю. Ежедневные отсутствия, эксперименты и условия не влияют на
  годовой подбор; при применении они сохраняются.
- §1.2: ограниченный потокобезопасный кэш хранит только исходный результат CP-SAT.
  Ключ включает режим, вариант, исходное состояние, базу и подсказку; отчёт
  конкретного запуска собирается на копии, без повторного накопления времени.
- §1.3–1.4: CP-SAT изолирован и при обычном запуске из исходников. Таймауты:
  день 30 с, неделя 60 с, распознавание 170 с. Это аварийные пределы процесса,
  а не время, которое пользователь выбирает или обязан ждать. stderr таймаута
  сохраняется в диагностике. В исходнике распознавание уже имело предел 170 с,
  а вычисление пути ресурсов уже находилось внутри try: эти замечания отчёта
  не соответствовали коду.
- §1.5: у резервов бюджета есть срок жизни. Зависший резерв переводится в
  консервативный расход, а не возвращается без доказательства отсутствия списания.
  Поздний ответ корректно пересчитывает резерв. Ошибка установления подключения
  не тарифицируется; read/write timeout после отправки сохраняет оценку расхода.
- §1.6: один ограниченный повтор после 429, временного отказа шлюза, ошибки
  подключения или некорректного JSON. Каждый потенциально оплаченный ответ
  учитывается отдельно. Усечённый ответ и неопределённый транспортный таймаут
  не повторяются автоматически. Всё проверено искусственными ответами.
- §1.7–1.8: нечётный набор в годовом редакторе не создаёт ложного разрыва
  существующей пары; предупреждение о неполной паре остаётся. Дневной подбор
  по-прежнему запрещает половину пары. Извлечение решения защищено от отсутствия
  выбранного слота, кабинета и соответствующей подгруппы.
- §1.9: mutex зависит от каталога данных, а не версии. Второй запуск не
  останавливает занятое первое окно. PID проверяется по живому локальному
  серверу; server.json удаляется владельцем. Окно нельзя закрыть во время
  диалога/записи отчёта, очередь записи завершается перед выходом.
- §1.10: общая проверка числового ввода, русские сообщения о некорректном
  запросе и неизвестном учителе. Нарушение целостности назначения останавливает
  подбор с понятным сообщением и не меняет расписание.
- §2: общие правила предметов вынесены в rules.py. Закреплённое исключение
  восьмого урока задаётся ID из проекта и переживает переименование учителя.
  Для старого импорта допустимо восстановить единственный уже существовавший
  восьмой урок; правило не выводится из фамилии. Клиент использует день правила.
  User-Agent берёт настоящую версию приложения.
- §3.1: у обычного, недельного и AI-предпросмотра единый PreviewStore:
  блокировка, копирование, TTL и постепенное FIFO-вытеснение.
- §3.2: SQLite-соединения закрываются в finally, включая историю диалогов,
  исключения и чтение времени сохранения. Автоматический бэкап — отдельный
  SQLite-файл через backup API, после первой и каждых 20 мутаций; сохраняется
  только один последний бэкап. Рабочая транзакция не копируется как сырой WAL.
- §3.3: ZIP-шаблоны закрываются, секции таблиц разбираются одним помощником,
  наличие нужных классов проверяется перед изменением документа. Дополнительная
  проверка каждой ячейки после заполнения остаётся.
- §3.4: общий slot_feasible для Greedy и CP-SAT, общий diff_lessons для журнала,
  включая совместные уроки и технологию.
- §3.5: повторная проверка объединения не дублируется; основа фамилии общая.
- §3.8: имя DOCX берётся из Content-Disposition сервера, скачивание имеет
  таймаут с понятным сообщением; время сохранения показывает часовой пояс
  компьютера пользователя.
- §4: копии Grid переиспользуют индексы, предпочтения и таблицу отсутствий;
  проверка дублей объединений использует индекс, журнал индексируется перед
  применением. Неподтверждённое обещание ускорения в 3–10 раз не используется.
- §5.1–5.2: чужие Origin, same-site и cross-site отклоняются также для GET;
  сохранённые нативные ссылки на отчёты ограничены 50 записями.
- §5.5–5.6: lock-файлы Word исключены из сборки. Школьные данные, документы,
  бэкапы, изображения диагностики и ключи исключены из Git.
- §6.1,6.4–6.7: локальный Git, закрытый список разрешённых файлов, проверка
  индекса перед коммитом, искусственный seed и публичные регрессии. Исторические
  патч-скрипты архивированы с запретом запуска. Runtime/dev зависимости разделены,
  pywin32 объявлен, lock содержит только дерево нужных зависимостей.
  PowerShell вызывает единый Python-сборщик. Перед сборкой обязательны тесты и
  сверка README с версией. Добавлен CI для Windows, который заработает только
  при отдельном решении разместить репозиторий на сервере.

## Не применять как исправление ошибки

Технология остаётся обязательной парой согласно требованиям школы. Совет сделать
это правило необязательным противоречит заданию. Фиктивная дата понедельника
в пробе модели не влияет на настоящее расписание.

Тарифы AI и возможности JSON Schema не переключаются наугад. Текущие маршруты
проверялись ранее; автоматического повышения цены или перехода на другую модель
нет. Для новых моделей нужна отдельная проверка официальных возможностей.

Массовое разрезание server/model/engine на сервисы и перенос всего фронтенда на
ES-модули — архитектурные предложения, а не установленные ошибки. Полный такой
рефакторинг в эту версию не входит. Действующие проверки независимы от поиска;
сохраняются CSP, экранирование пользовательского текста и обработка старта.
inline style пока используется для размеров и части оформления; его удаление
требует отдельной визуальной проверки. Неизмеренные оптимизации deepcopy и
полностью инкрементальный скоринг тоже не заявляются выполненными.

Существующие частные тесты и исторические материалы не переименованы массово:
они исключены из Git, а исходные бэкапы сохранены. Старые установщики не удалены.
Это сохраняет возможность восстановления. Новые публичные тесты не требуют
настоящего расписания; длительные проверки можно запускать с маркером slow.

79 старых временных каталогов pip/pytest перенесены из корня проекта в локальный
архив build/temporary-archive-20261110, без удаления файлов.

При проверке установщика обнаружена нехватка места на диске. Удалён 21 устаревший
распакованный каталог build/distribution; две актуальные сборки сохранены.
Это воспроизводимые копии, не рабочие данные. После очистки свободно около
31 ГиБ. Документы, базы, их резервные копии и готовые установщики сохранены.

## Проверка

Результаты полного набора и проверки собранного установщика сохраняются локально
в docs; эти артефакты в Git не включаются. Сетевые вызовы к настоящему AI при
данном исправлении не выполнялись. Проверка на мамином ноутбуке по-прежнему
требует самого устройства и его диагностического отчёта.

Полный набор: 345 тестов. Копия только Git-исходников без школьных данных:
33 теста. Проверка индекса: 0 обнаруженных фамилий, ключей и закрытых путей.
Проверка защиты отдельно подтвердила блокировку закрытого пути, искусственной
фамилии и тестового ключа без вывода их содержимого.
